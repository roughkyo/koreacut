# koreacut 개발 과정

## 1. 배포본 분석

Craft Anything v0.5.0을 Windows에서 실행하고, ReaCut v0.7.1 macOS 배포본에서 Electron 앱을 담은 `Contents/Resources/app.asar`를 확인했습니다.

```powershell
& $craft triage --deep $asar
& $craft --deep js-app-map --input-path $asar --limit 15
```

정적 분석에서 `dist/index.html`, `dist-electron/preload.cjs`, `dist-electron/main.cjs`를 찾았습니다. Craft Anything은 IPC 채널 58개를 보고했고 이 중 8개는 양쪽 호출을 연결했습니다. 이후 공개 소스에서 `export-project` 요청이 `startExport`로 전달되는 코드를 확인했습니다. 이 수치는 부분 분석 결과이며 macOS 앱의 실행 결과는 포함하지 않습니다.

## 2. 한국어판 구현

공개 소스를 기반으로 koreacut을 개발했습니다. 한국어를 기본 언어로 설정하고 메뉴, 오류 메시지, 내장 소재 이름을 번역했습니다. 중국어가 들어 있던 템플릿 미리보기 3장도 한국어로 다시 렌더링했습니다.

자막 가져오기와 영상 내보내기 CLI는 기존 편집기 로직을 재사용합니다. Windows에서 긴 필터 그래프는 파일로 전달해 명령줄 길이 제한을 피합니다.

## 3. Windows 패키징과 확인

FFmpeg 9.0.2, x264, zlib 1.4를 소스에서 빌드했습니다. Windows 포터블 앱이 같은 패키지에 들어 있는 FFmpeg와 FFprobe를 사용하도록 연결했습니다.

외부 FFmpeg 경로를 비운 Windows에서 PNG와 오디오가 있는 MP4를 불러와 2초 H.264/AAC MP4로 내보냈습니다. 단일 EXE가 푼 ASAR, FFmpeg, FFprobe의 SHA-256이 검증에 사용한 패키지와 일치했습니다. 패키지의 텍스트 파일 1,964개를 검사해 한자 문자 0건을 확인했습니다.

## 4. 공개 범위

저장소에는 앱 소스, 빌드 레시피와 작업 기록을 공개합니다. 원본 ReaCut의 저작권과 라이선스는 `LICENSE` 및 제3자 고지에 남겼습니다.


공개 전 `.gitignore`가 환경 설정, 실행 파일, 빌드 출력, 개인 프로젝트와 영상을 제외하는지 확인했습니다. 추적할 파일에서 토큰, 개인 작업 경로, 전화번호 형식과 이미지 EXIF·XMP를 검사했습니다. 내장 미디어 도구의 빌드 경로는 공개용 경로로 바꾼 뒤 패키징과 MP4 내보내기를 다시 확인했습니다.
